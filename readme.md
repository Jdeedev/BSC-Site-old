## About

BlackShot Garena (2015) — Static Restoration is a fan-made project created to preserve and recreate the visual identity and structure of the original BlackShot Garena website from its classic era.

This project delivers a cleaned and static version suitable for modern hosting platforms, maintaining the original layout, assets, and nostalgic experience.
